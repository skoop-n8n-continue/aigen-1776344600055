# Lahore Weather + Clock Web App

A modern, responsive weather and clock application optimized for Lahore, Pakistan.

## Features

- **Real-time Clock**: Digital (12h/24h) and Analog modes.
- **Current Weather**: Temperature, feels like, humidity, wind, UV index, and AQI.
- **Forecast**: 24-hour hourly forecast and 7-day daily forecast.
- **Location**: Defaulted to Lahore, with city search and auto-location detection.
- **Dynamic UI**: Glassmorphism, dark/light modes, and dynamic backgrounds based on weather conditions.
- **Offline Support**: Caches last fetched weather data.
- **Auto-Refresh**: Updates weather every 15 minutes.

## Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **HTTP Client**: Axios

## Setup Instructions

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Add API Key**:
    - Open `src/context/WeatherContext.jsx` or `src/services/weatherService.js`.
    - Replace `YOUR_OPENWEATHER_API_KEY` with your actual OpenWeatherMap API key.

3.  **Run Development Server**:
    ```bash
    npm run dev
    ```

4.  **Build for Production**:
    ```bash
    npm run build
    ```

## Responsive Breakpoints

- **Mobile**: Vertical layout, compact clock, swipeable forecast.
- **Tablet**: Vertical stack, medium clock, card-based layout.
- **Desktop**: Large hero section, side-by-side details, full-width forecast.
